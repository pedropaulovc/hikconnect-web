# CCTV Demo App Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** A simple Ionic React + Capacitor demo CCTV app with live footage, past recordings, multiple cameras, and a per-camera activity feed of detection events — fully mocked, public sample video.

**Architecture:** Ionic React + Vite (TypeScript). Static build (`dist/`) wired to Capacitor (`webDir: dist`), web-only this pass (Android added later via `npx cap add android`). Three tabs — Live, Recordings, Events. Mocked data modules under `src/data/`. `hls.js` for live HLS; native `<video>` for MP4 recordings.

**Tech Stack:** Ionic React 8, React 19, Vite 6, TypeScript (strict), Capacitor 6, hls.js, Vitest + Testing Library.

---

## Conventions (apply to every task)

- Enums as const objects or string unions — never booleans across component boundaries.
- Flat code, early returns, avoid `else`.
- No backwards-compat shims.
- Commit after each task with `--no-verify` (no husky hooks on this branch).
- Repo root is the project root (orphan `feature/cctv-demo` branch, blank tree).

**Step 3: Implement.** `types.ts`:

```ts
export type CameraStatus = 'online' | 'offline';
export type DetectionType = 'person' | 'vehicle' | 'motion' | 'animal';

export interface Camera {
  id: string;
  name: string;
  location: string;
  status: CameraStatus;
  posterUrl: string;
  liveStreamUrl: string;
}

export interface DetectionEvent {
  id: string;
  cameraId: string;
  type: DetectionType;
  timestamp: string;
  thumbnailUrl: string;
  recordingId?: string;
}

export interface Recording {
  id: string;
  cameraId: string;
  start: string;
  end: string;
  durationSec: number;
  videoUrl: string;
  thumbnailUrl: string;
}
```

`cameras.ts` — 4 cameras (Front Door, Lobby, Parking Lot, Backyard), mix of online/offline.
Use these sample assets:
- Live HLS: `https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8` (and Apple bipbop `https://devstreaming-cdn.apple.com/videos/streaming/examples/img_bipbop_adv_example_ts/master.m3u8`).

`events.ts` — ~12 detection events across cameras, varied types and timestamps (recent, ISO), thumbnails via `https://picsum.photos/seed/<eventId>/320/180`, some link a `recordingId`.

`recordings.ts` — ~8 recordings across cameras, MP4 `videoUrl`s from Google sample bucket
(e.g. `https://storage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4`,
`ForBiggerBlazes.mp4`, `ForBiggerEscapes.mp4`), thumbnails via picsum.
